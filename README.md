# cinco-noches-en-la-unraf

Juego de terror y supervivencia 2D tipo FNAF — guardia nocturno de la UNRAF. Sobrevive hasta las 6 AM.

Stack: Phaser 4 + Vite + JavaScript. Solo PC (teclado + mouse).

## Scripts

- `npm install` — instalar dependencias
- `npm run dev` — verificación manual en PC
- `npm run build` — validar bundle Vite + Phaser
